# Soccer World

Ein asynchrones Multiplayer-Strategiespiel für Freundesgruppen: Jeder besitzt einen
Fußballverein, alle teilen sich denselben Transfermarkt, und am Ende der Saison gibt es
nicht einen Sieger, sondern acht.

**Status:** Konzeptphase — noch keine Implementierung.
